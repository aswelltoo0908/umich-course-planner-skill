# Planning output schema

## Recommendation

- Target term and timestamp
- Primary schedule table: course, section, component, instructor, days, time, location, credits, seat/waitlist state
- Weekly grid with travel warnings
- Requirement mapping: prerequisite/core/category/distribution/degree-only
- Instructor comparison: Atlas metrics, public-review signal, sample size, confidence
- Total credits and workload assessment
- Exact registration order and backups

## Required labels

- `Verified`: current official source
- `Historical`: Atlas or prior-term data
- `Inference`: reasoned recommendation
- `Unknown`: unavailable or insufficient evidence

## Privacy-safe example

`Student has completed introductory programming and is planning the discrete mathematics core.`

Do not include a student name, UMID, uniqname, email, phone, login state, private transcript, or raw degree-audit export.
