# UMich Course Planner

An independent, free, skills-only course-planning assistant created by Haotian Zhang (Hilbert). It helps users compare University of Michigan courses, instructors and schedules using available public sources and their own authenticated sessions. It is not an official University of Michigan service and is not endorsed by the university. Course details and availability can change and must be verified with official sources.
